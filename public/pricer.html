The Pricer Agent

Turns every recipe the Scout Agents save into a Kroger shopping cart with prices, so the Planner Agents can compare recipes by cost. Nobody has to start it: it prices each new recipe by itself.

  1. A Scout Agent saves a recipeThe coordinator hands it to the Pricer Agent straight away.
  2. The Pricer Agent builds a shopping cartFor each ingredient it searches Kroger, picks a product, and decides how much the recipe needs.
  3. The Pricer Agent does the mathsPackages to buy, the cart total and the cost per serving.
  4. The Pricer Agent saves the priceTo the coordinator, where the Planner Agents read it.
