The Pricer agent

Turns every recipe the Scouts save into a Kroger shopping cart with prices, so the Meal Planners can compare recipes by cost. Nobody has to start it: it prices each new recipe by itself.

  1. A Scout saves a recipeIt joins the Pricer’s queue straight away.
  2. The AI choosesFor each ingredient it searches Kroger, picks a product, and decides how much the recipe needs.
  3. Code does the mathsPackages to buy, the cart total and the cost per serving. The Meal Planners read the result.

2Its instructions

The prompt the agent follows: how many people the cart feeds, how to choose products, and when to skip an ingredient. Saving changes it for recipes priced from then on; Save and re-price every recipe also applies it to the recipes already priced.
