For the instructor

Backup agents

Run any of the four agents from here. Your own Scout Agent and Meal Planner Agent are a backup if a group’s Lovable app isn’t working: they work like the students’ agents, over MCP, under the group you choose. The Recipe Pricer and the Shopper Agent run on the site. Everything shows up on the Coordinator page.

Signed in.

Agent 1 Scout Agent

Finds four real recipes on TheMealDB for a theme and saves them to the coordinator. The Pricer Agent then prices them.

Agent 3 Meal Planner Agent

Plans five dinners, Monday to Friday, from the priced recipes, checks the plan with the coordinator and saves it.

Agent 2 Recipe Pricer

Prices every new recipe by itself. Use these when you need to step in; watch it work on the Recipe Pricer page.

Agent 4 Shopper Agent

Chooses the class’s best meal plan from the saved ones and has the coordinator build its Kroger shopping list, scaling the plan (priced per person) to the number of people below. The new choice becomes the active shopping plan; the previous one is kept as an earlier choice.
