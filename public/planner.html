Agent 3

Build the Meal Planner

An agent that takes a budget, reads the recipes the Scout Agents found and the Pricer Agent priced, and plans five dinners, Monday to Friday, that are nutritious, varied and cheap. It shows the week, lists the ingredients to buy and the total price and saves the plan to the coordinator.

Build it in stages

You’ll build Meal Planner in three stages. First, you’ll create a simple interface. Then you’ll connect it to the class coordinator to read the recipes the Scout Agents found and the Pricer Agent priced. Finally, you’ll add an AI agent that plans the week, checks it with the coordinator and saves it.

You will change and rework parts of the app as you go. That is intentional. The goal is to understand how the system develops—not to build the perfect application on the first attempt.

Each step has a goal, a sample prompt to copy into Lovable (use it as it is or change it), what you should see, and things you can try before moving on.

Step 1Build the interface

Goal

Create the page where you enter a budget, dietary requirements and preferences, and where the week will appear. There is no AI, backend or recipe data yet.

Sample prompt

What you should see

  • The mock interface of the app

Things you can try

  • Feel free to make changes to make it your own

Don’t spend too long polishing. You will change the interface as the agent develops.

Step 2Connect to the coordinator

Goal

Connect the app to the coordinator’s MCP server, look at the actions (tools) it offers and use them to show the recipes the class has saved, with the prices the Pricer Agent worked out. There is no AI yet.

Recipe Scout + Recipe Pricer → Coordinator → Meal Planner

The class key never goes in a prompt. This step asks Lovable to create a secret. Lovable then shows a secure box where you paste the key. The prompt uses your group name from Before you start on the Welcome page: {{GROUP}}.

Sample prompt

What you should see

  • A successful connection message
  • The tools provided by the coordinator and a description of what each tool does
  • How the coordinator works: the plan format, the checks and the limits
  • A table of the class’s priced recipes. If it is empty, the Scout Agents haven’t saved recipes yet or the Pricer Agent is still working on them.

Things you can try

  • Read the checks the coordinator applies to every plan.
  • Look for your connection on the Coordinator page.
  • Discuss which tools the Meal Planner Agent should use, and in what order.

The Meal Planner never talks to the Scout Agents or the Pricer Agent directly. It reads their work from the coordinator, which stores the recipes and prices and describes how to use them.

Step 3Add the Meal Planner Agent

Goal

Add an AI agent that learns how to work with the coordinator, chooses five dinners, asks the coordinator to check the plan, improves it and saves it so the rest of the class can see it.

Sample prompt

What you should see

  • The Meal Planner Agent learns how to work with the coordinator at the beginning of the run.
  • It drafts a plan, asks the coordinator to check it and changes dinners when a check fails.
  • Five dinners fill Monday to Friday, each showing which groups picked it, with a shopping list, the average cost of a dinner against the budget and each check marked ✓ or ✗.
  • The outcome: valid plan found, no feasible plan found, or run failed, with an explanation.
  • The saved plan appears on the Coordinator page under your group.

Things you can try

  • A tiny budget, such as $1 a dinner. Does it explain that it can’t be done, or pretend?
  • Vegetarian only when there are fewer than five vegetarian recipes.
  • A rule of your own, such as no dinner over 45 minutes.
  • Change one Meal Planner Agent instruction and compare its behavior.
  • Experiment with different instructions and goals, such as food from a different continent every day.

The important question is not only “Did it save a plan?” Also ask: “Did it fix the checks that failed, and are its explanations honest?”

The checks the coordinator applies to every plan
  • The average dinner costs no more than the budget, per person
  • At least 3 different cuisines
  • No category (e.g. Beef, Chicken) more than 2 times
  • At least one vegetarian or vegan dinner

All worked out from real data: the Pricer Agent’s costs and each recipe’s cuisine and category. Nutrition isn’t checked; making the week nutritious is a goal for your Meal Planner Agent. A plan that fails a check is still saved, with the check marked ✗.
