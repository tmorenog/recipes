Backup and restore

Back up

Downloads every recipe, meal plan and activity entry as one file. Do this before class, and before any restore or reset.

Restore

Replaces everything in the database with a backup file. The file is checked first; if anything in it is wrong, nothing changes.

    Neon also keeps its own history of the database. If a backup file isn’t enough, open the database from Vercel’s Storage tab (“Open in Neon”) and use its restore feature to go back to a point in time.
