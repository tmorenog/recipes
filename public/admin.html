Backup agents

If a group’s Lovable app isn’t working, run your own Scout Agent or Planner Agent from the site. They use the coordinator like any student agent, under a group name you choose, with the AI key the Pricer Agent uses.

Prompts

While you’re signed in here, every step on the Recipe Scout and Meal Planner pages has an Edit button: change a sample prompt, save it, and every student sees the new version. Back to the default returns a step to its original text. The Pricer agent’s own instructions are on the Pricer page.

Kroger

The Pricer signs in to Kroger with KROGER_CLIENT_ID and KROGER_CLIENT_SECRET. This checks that they work and that Kroger finds a store.

Backup and restore

Back up

Downloads every recipe, meal plan and activity entry as one file. Do this before class, and before any restore or reset.

Restore

Replaces everything in the database with a backup file. The file is checked first; if anything in it is wrong, nothing changes.

    Load the sample database

    If something goes wrong in class, replace everything with a ready-made database, always the same: 20 real TheMealDB recipes picked by five groups. No meal plans or activity. Download a backup first if you want to keep what’s there.

    Neon also keeps its own history of the database. If a backup file isn’t enough, open the database from Vercel’s Storage tab (“Open in Neon”) and use its restore feature to go back to a point in time.

    Logs

    Exchange log

    Every request agents sent to the coordinator and its answer, shown live on the Coordinator page. It keeps the newest 2,000. Clear it before a class so students see only their own session.

    Activity log

    Every save and mark attempt, including admin changes, kept for backups. Clearing it doesn’t touch recipes or meal plans.

    Start over

    Deletes all recipes, meal plans and activity, for example between two classes. Download a backup first.
