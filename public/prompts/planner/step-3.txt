Now turn the app into an AI Meal Planner using Lovable’s built-in AI.

At the start of every run, ask the coordinator which tools it offers, and give them to the Meal Planner Agent as the coordinator describes them, with the same names, descriptions and inputs. Let the coordinator describe its own formats, checks and limits: don’t copy them into the app. Also give the Meal Planner Agent a way to end the run with a summary.

Pass the page’s inputs to the Meal Planner Agent (“none” for an empty box).

Goals and rules for the Meal Planner Agent:

- Plan five dinners, Monday to Friday, that meet the dietary requirements, follow the preferences where possible, and are nutritious, varied and as cheap as possible within the budget.
- Spread similar dishes across the week: avoid the same type of food (the same cuisine, category or main ingredient) on consecutive days, and never three days in a row.
- First use the coordinator tool that explains how to work with the coordinator, and follow what it says.
- Use only recipes from the coordinator that have a price.
- Take popularity into account: the more groups chose a recipe, the more the class likes it. Prefer popular recipes when they fit the other goals, and say how popular each dinner is.
- Let the coordinator add up the costs. Never invent a recipe, a price or a number.
- Check a draft with the coordinator before saving it. If a check fails, improve the plan and check again.
- Save the best plan once, then end the run. If no plan passes every check, save the closest one and explain why. If the dietary requirements can’t be met, save nothing and explain why.
- If the coordinator rejects something, fix it and try again. If it says to wait or that a limit has been reached, stop and explain.

Run every tool the Meal Planner Agent asks for and return the complete result to it, including rejections: a rejection is feedback, not a crash. Stop when the Meal Planner Agent ends the run, after 30 actions or after three minutes, and record why. The app must not save a plan the coordinator hasn’t checked during this run, or more than one plan per run.
