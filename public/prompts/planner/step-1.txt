Build a web app called “Meal Planner” for a class exercise.

The goal of Meal Planner is to plan five dinners, Monday through Friday, using recipes that Scout Agents have found and the Pricer Agent has priced. It will eventually use AI to:

- Take a budget, dietary requirements and preferences from the user
- Read the recipes saved by the class, with their prices
- Choose five dinners that are nutritious, varied and affordable
- Save the plan through the coordinator so the rest of the class can see it

For this first step, build only the interface. Do not add AI, a backend, a database or connections to other services yet.

Include the following items:
- A number input for the maximum average budget per person per dinner, in US dollars (default: 15, minimum: 1)
- A text box with “Dietary requirements” (Examples: “vegetarian only”, “no pork”, “no peanuts”). Explain that these are hard constraints.
- A text box with “Preferences” (Examples: “we like spicy food”, “prefer quick dinners”). Explain that these are preferences, not hard requirements.
- A “Plan my week” button.
- A “What the Planner Agent is doing” panel. Leave it empty for now.
- A “The week” panel with five empty cards:
   Monday, Tuesday, Wednesday, Thursday and Friday.
- An empty outcome area that will eventually show one of:
   - Valid plan found
   - No feasible plan found
   - Run failed

Nothing needs to happen when the button is pressed yet.

Make the page warm, inviting, responsive and accessible.
