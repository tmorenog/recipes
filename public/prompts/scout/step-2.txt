Now turn the app into an AI Recipe Scout using Lovable’s built-in AI.

Give the Scout Agent all the recipe actions you already created (the ones in the Recipe Tool Lab) so it can decide which ones to use and in what order.

Also give it a way to:

- Add a recipe to its final selection and explain why it was chosen
- End the search and summarize what happened

These are the goals and rules for the Scout Agent:

- The Scout Agent has to try to find four real recipes that fit the user’s dinner theme.
- It can use the available recipe actions to search in different ways.
- Before selecting a recipe, it has to retrieve and examine its complete ingredients and instructions.
- The Scout Agent cannot invent a recipe.
- It has to choose a varied set and briefly explain why each recipe fits the theme.
- It cannot select the same recipe twice.
- If it cannot find four suitable recipes, it should stop and explain what prevented it from completing the request.

Run each action requested by the Scout Agent, return the result to it, and let it decide what to do next. Continue until the Scout Agent finishes, uses 25 actions, or reaches two minutes. Record why it stopped.

The app must enforce these rules:

- A recipe cannot be selected unless its complete details were retrieved during the current run.
- The same recipe cannot be selected twice during one run.
- No more than four recipes can be selected.

Update the page:

- The “Scout recipes” button starts the Scout Agent

- Add a “What the Scout Agent is doing” area that shows searches, recipe lookups, results and errors as they happen
- Show selected recipes with their photos, names, cuisines and selection reasons
- Show how many actions the Scout Agent has used
- Disable the button while the Scout Agent is working

Save what happens (actions, results, status messages and errors): what the agent does, not its private thinking.
