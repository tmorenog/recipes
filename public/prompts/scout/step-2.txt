Now turn the app into an AI Recipe Scout using Lovable’s built-in AI.

Give the Scout Agent all the recipe actions you already created (the ones in the Recipe Tool Lab), so it can decide which ones to use and in what order. Also give it a way to add a recipe to its selection, with why it was chosen, and a way to end the search with a summary.

Goals for the Scout Agent:

- Find four real recipes that fit the user’s dinner theme, searching in different ways.
- Choose a varied set, and briefly explain why each recipe fits the theme.
- Never invent a recipe. If four suitable recipes can’t be found, stop and explain why.

Run each action the Scout Agent asks for and return the result to it. Stop when it finishes, after 25 actions or after two minutes, and say why it stopped.

The app checks every selection: a recipe can be selected only after its complete details were retrieved during this run, only once, and no more than four in all. Return a refused selection to the agent with the reason, so it can adjust.
