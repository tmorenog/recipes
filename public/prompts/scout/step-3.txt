Add the agent: a backend function run-scout that uses Lovable AI with tool calling, the five TheMealDB tools, and two more tools:
- choose_recipe(meal_id, why_chosen): adds a recipe to this run's chosen recipes
- finish(summary): ends the run

How it runs:
- Run the tools the model asks for and send back the results until it calls finish, or until 25 tool calls or 2 minutes (constants I can change). Record why it stopped.
- Save every step (thought, tool call, result, error) to a table agent_steps as it happens.

Instructions for the model:
"You are Recipe Scout. Find 5 real recipes on TheMealDB that fit the theme. Search in several ways, and call get_recipe to read the full recipe before choosing it. Never invent a recipe. Choose varied recipes, and call choose_recipe for each with one sentence on why it fits. Call finish when you have 5, or explain why the theme can't be met."

Connect the page: "Run Recipe Scout" starts a run with the theme. "What the agent is doing" shows each step live. "Chosen recipes" shows each chosen recipe with its photo, name, cuisine and why it was chosen.
