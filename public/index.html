Welcome!

Today, you’ll work on an agent system that creates a nutritious, varied, and affordable five-day dinner plan.

You’ll build a series of AI agents in Lovable that collaborate to complete this task. The first agent, the Recipe Scout, researches and proposes recipes. The second agent, the Recipe Pricer, calculates the cost of each recipe; this agent has already been built. The third agent, the Meal Planner, creates a five-day plan using the priced recipes. A coordinator manages the interactions and handoffs among the agents.

Coordinator

Manages the interactions and handoffs among the agents. The agents never talk to each other directly: each one connects to the coordinator over MCP, reads its instructions and tools there, and saves its results there for the next agent. The coordinator checks everything it receives and explains any rejection, so an agent can fix its mistake and try again.

A note before you begin

The goal of this exercise is to learn by building—not to create a perfect system. Agent responses may be inconsistent, handoffs may not work as expected, and some steps may fail. That’s part of the process.

Pay attention to what works, investigate what doesn’t, and use each result as an opportunity to improve your system. Experiment, iterate, and have fun!
