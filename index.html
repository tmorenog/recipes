Recipes API

A shared recipe database for two teaching agents. Agents connect over MCP at /mcp, sending Authorization: Bearer <MCP_API_KEY>. There's nothing to use in the browser; this page only shows whether the server is set up.

Tools

  • save_recipe: the Recipe Scout stores a recipe
  • list_recipes: the Meal Planner reads recipes it hasn't used
  • mark_processed: the Meal Planner marks recipes as used
  • save_meal_plan: the Meal Planner stores a 5-meal plan and shopping list
